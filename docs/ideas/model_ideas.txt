Potential models to investigate on our diffspot dataset

- DinoV2 (from proposal)
- ChangeFormer (from proposal)

- DinoV3 is successor to DinoV2, came out in 2025 vs DinoV2 in 2023, has roughly 6x larger model size and 12x more training data compared to DinoV2
https://ai.meta.com/research/dinov3/


For feature extraction / identifying regressions
- BIT / Bitemporal Image Transformer
- Siamese ViT/ConvNet (pairwise feature comparison)
- CLIP / SigLIP (for image/text semantics)
- UI-specific models such as UIClip (can understand UI appearance)


For describing what the regression is
- VLM/LVLM

We will probably have some model to first extract features, and then use something like VLM/LVLM to describe what the regression is



Currently the dataset classifies all the types of mutations we added as regressions, nothing is benign. It would be interesting to test how well it performs without any benign examples in the training set, and maybe add them later.
