Regression Lens model ideas (exploratory)
=========================================

Status: brainstorming only. This file does not select a final model or override
the dataset, label, split, or evaluation decisions in docs/adr/.

Paired-image detection/localization candidates
----------------------------------------------

- Pixel-difference and SSIM baselines
- LPIPS
- DINOv2 paired-feature approaches (from the proposal)
- ChangeFormer (from the proposal)
- DINOv3, the successor to DINOv2
  https://ai.meta.com/research/dinov3/
- BIT / Bitemporal Image Transformer
- Siamese ViT or ConvNet
- CLIP / SigLIP
- UI-specific representation models such as UIClip

Regression description candidates
---------------------------------

- A VLM/LVLM could eventually describe a regression after a detection/localization
  model identifies the relevant visual evidence.
- Natural-language descriptions are a probable extension, not part of the first
  trustworthy data-generation milestone.

Data and evaluation constraints
-------------------------------

- DiffSpot is the external benchmark, not a training or model-selection dataset.
- Intentional visible CSS/DOM mutations are regressions. Benign/no-change examples
  are generated separately; mutation size alone does not justify a benign label.
- All candidates should use the same source-page-disjoint splits and versioned
  evaluation protocol so their results remain comparable.
