and `train_val_split.ipynb`. `archive/CSC490_data_mutation_early.ipynb` preserves
the different early root notebook; it does not replace the current source.

accepted dataset. General validation is already complete. Use the committed
`../splits/splits_85_15.json` unchanged, including its 25 exclusions. Changing
data needs an explicit version/protocol. HTML, screenshots and generated
metadata stay outside Git. Model notebooks live under `../../notebooks/`.
